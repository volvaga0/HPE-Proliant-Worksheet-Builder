The European Union (EU) eco-design regulations for server and storage products, known as ErP Lot 9, will go into effect on 01

offer multiple power output options, allowing users to "right-size" a power supply for specific server configurations. This flexibility
helps to reduce power waste, lower overall energy costs, and avoid "trapped" power capacity in the data center.

each standard AC power supply option kit. If a different power cord is required, please check the ProLiant Power Cables web
page.

HPE Server UEFI/Legacy ROM

Unified Extensible Firmware Interface (UEFI) is an industry standard that provides better manageability and more secured
configuration than the legacy ROM while interacting with your server at boot time. HPE ProLiant Gen10 servers have a UEFI Class 2
implementation and support both UEFI Mode (default) and Legacy BIOS Mode.
Notes: The UEFI System Utilities function is analogous to the HPE ROM-Based Setup Utility (RBSU) of legacy BIOS. For more
information, please visit http://www.hpe.com/servers/uefi.

UEFI enables numerous new capabilities specific to HPE ProLiant servers such as:
     · Secure Boot and Secure Start enable for enhanced security
     · Operating system specific functionality
     · Support for > 2.2 TB (using GPT) boot drives
     · USB 3.0 Stack
     · Embedded UEFI Shell
     · Mass Configuration Deployment Tool using iLO RESTful API that is Redfish API Conformant
     · PXE boot support for IPv6 networks
     · Workload Profiles for simple performance optimization

Memory

HPE Standard Memory UDIMMs has passed the rigorous Hewlett Packard Enterprise qualification and testing processes.
The memory subsystem in this server supports UDIMMs. The server supports single-rank and dual-rank DDR4 UDIMMs operating
at up to 2666 MT/s DIMM speeds.

Memory Population guidelines

     · The server supports two channels per processor with two DIMMs per channel for a total of four DIMMs per DL20 Gen10
         Server.

General Memory Population Rules and Guidelines:
     · Only UDIMMs are supported on DL20 Gen10. No support for RDIMMs and LRDIMMs.
     · All the channels in a system run at the fastest common frequency.
     · Both single DIMM per channel and dual DIMMs per channel are supported at 2666MT/s.
